- **서사 확장**: 별명 자동 생성, 팀 내 주전 경쟁 → 라이벌 진화, 코치/후배/프런트 관계, 언론 관심도, 은퇴 시 "이번 생의 기록" 하이라이트.
- **모바일**: 하단 5탭 네비게이션(경기·선수·리그·기록·역사).
- **밸런스**: 확률 시스템 도입에 맞춰 520회 자동 플레이로 재검증 (3. 밸런스 검증 섹션 참고). `runBalanceTest(n)`을 콘솔에서 직접 실행 가능.

# 야구 인생 — 2차 개발 노트 (리그 시뮬레이션 버전)

`baseball-life.html` 한 파일로 동작합니다. 브라우저에서 열면 바로 실행됩니다. 설치·빌드·서버 불필요.

이번 버전의 핵심 변화: **리그 1위 기록을 확률로 만들던 방식을 없애고, 실제로 존재하는 가상 리그 전체를 매년 시뮬레이션**합니다. 홈런왕은 확률분포가 아니라 그해 실제로 홈런을 가장 많이 친 선수입니다.

---

## 1. 이번에 구현된 것

### 가상 세계 (Phase 1)
- **World Seed** — 새 게임마다 새로운 야구 세계. 세이브에 시드가 포함되어 세계가 일관되게 유지됩니다
- **선수 DB 약 300명** — 10개 구단 × (1군 20명 + 2군), 전원 고유 ID·이름·나이·포지션·능력치·잠재력·스타일(거포형/교타자형/제구형 등)
- **이름 생성기** — 시드 기반 조합 생성 + 실존 선수 이름 차단 목록
- AI도 플레이어와 **같은 능력치 체계·같은 경기 계산식**을 씁니다. 타율·홈런·ERA·WAR이 같은 공식에서 나옵니다
- **성장과 노쇠화** — 잠재력을 향해 22세까지 빠르게, 26세까지 완만하게 수렴하고 30세부터 신체 능력부터 무너집니다
- **세대 교체** — 매년 신인 25~30명 입단, 노쇠·부진 선수 은퇴/방출. 20년 뒤 리그는 완전히 다른 얼굴입니다

### 리그 생태계 (Phase 2)
- **1군/2군, 콜업·강등** — 포지션별 정원이 고정되어 있어 능력치가 밀리면 내려갑니다. 2군에서 성장한 선수가 어느 해 갑자기 1군에 등장합니다
- **AI 트레이드·FA** — 매 오프시즌 구단 성향(육성형은 베테랑↔유망주 교환 선호)에 따라 선수가 실제로 이동합니다
- **플레이어 트레이드** — 팀 순위·성적·나이·감독 관계에 따라 제안이 들어옵니다. 수용도 거절도 결과가 남습니다
- **실제 순위표** — 로스터 전력으로 144경기 승수를 계산, 5위까지 포스트시즌, 브래킷 시뮬레이션으로 우승팀 결정
- **실제 시상** — MVP·신인왕·골든글러브·올스타·홈런왕·다승왕·타율왕·탈삼진왕·평균자책 1위를 리그 전체 기록으로 뽑습니다. AI도 수상 이력이 쌓입니다

### 서사 (Phase 3)
- **구단 성향/문화** — 10개 구단이 FA·트레이드·육성·베테랑 선호도와 공격/수비/투수 지향을 각각 다르게 가집니다
- **구단 전용 이벤트** — 이적하면 이벤트 풀이 통째로 바뀝니다 (스타 중심 구단의 견제, 육성 구단의 "실패해도 된다", 팬덤 구단의 야유, 데이터 구단의 리포트 등)
- **특성 조합 전용 스토리 8종** — [홈런왕]+[강심장] → "큰 경기의 거포" 처럼 조합이 서사와 수치 양쪽에 영향
- **라이벌이 실제 선수** — 리그 DB에 등록된 AI로 독립적으로 성장·수상·FA 이적·은퇴합니다. 은퇴 화면에서 그의 통산 성적을 확인합니다

### 역사 (Phase 4)
- **월 단위 시즌** — 4~5월 / 6~7월 / 8~9월 세 구간 + 포스트시즌, 구간마다 결정적 순간에 개입
- **경기 로그** — 맹타·호투 기록이 쌓이고, 노히트노런·퍼펙트게임·사이클링히트는 **역사적 경기**로 리그에 영구 기록됩니다
- **통산 기록 달성** — 2000안타·300홈런·200승·2000탈삼진 등 마일스톤이 연표에 남습니다
- **리그 기록실** — 단일시즌/통산 최고 기록을 누가 언제 세웠는지 추적. 은퇴 시 내 기록이 역대 몇 위인지 표시
- **은퇴 후 연대기** — 내 커리어뿐 아니라 *내가 살았던 시대*를 보여줍니다. 시대 최고 선수 TOP5 속 내 순위, 그 시대의 왕조, 라이벌의 최종 성적, 역사적 경기, 그리고 **내가 은퇴한 뒤 떠오르는 다음 세대 유망주**
- **명예의 전당** — 플레이어와 AI 레전드가 통산 WAR 기준으로 함께 정렬됩니다

### UI (Phase 5)
- 940px 이하에서 1열 카드 레이아웃, 상단 정보 바 고정(sticky)
- 선택지 버튼 최소 높이 60px, 하단 버튼 전체 너비 — 한 손 조작 가능
- 입력 폰트 16px로 iOS 자동 확대 방지, 터치 기기는 hover 대신 press 피드백
- 기록표는 가로 스크롤 영역으로 분리해 레이아웃이 깨지지 않게 처리
- 새 탭 5종: 기록 / 커리어 / **리그**(순위표·시즌 리더·우리 팀 로스터·라이벌) / **역사**(리그 기록·연도별 역사·내 경기 로그) / 스토리

### 유지된 기존 시스템
특성 70종·6슬롯·진화·조합, 훈련 trade-off, 잠재력, 성장곡선, 컨디션, 피로도, 부상, 스토리 플래그, 결정적 순간, 시상, 포스트시즌, 국가대표, FA, 은퇴, 엔딩 14종, 저장/이어하기, 명예의 전당 — 전부 그대로 살아 있습니다.

## 2. 아직 없는 것
- 외국인 선수, 지명권 트레이드, 연봉/계약 금액 시뮬레이션
- 시즌 중 트레이드 (현재는 오프시즌만)
- AI 선수 개인의 스토리 이벤트, AI 국가대표 명단
- 구단별 이벤트가 구단당 1~3개 (기획서 목표는 5~10개). 배열에 추가만 하면 늘어납니다

## 3. 밸런스 검증 (v2.1 — 520회 표본)

확률 기반 선택지 도입 후 밸런스가 크게 바뀌어 재검증했습니다. 파일에 결과를 이어 쓰는 배치 방식으로 총 520회를 실행했습니다.

| 지표 | 값 |
|---|---|
| 통산 WAR | 25% 지점 7 / 중앙값 21.4 / 75% 지점 37.7 / 95% 지점 65.4 |
| 커리어 길이 | 평균 15.3시즌, 부상 평균 2.3회 |
| 최고 능력치 관측값 | 99.8 (100 상한 정상 작동) |
| 올스타 | 평균 3.2회/커리어 |
| 리그 홈런왕 | 평균 37.8개 |
| MVP 시즌 WAR | 평균 6.2 |
| AI 통산 1위 WAR | 평균 67 |
| 1군 인원 | 평균 200명 (고정값과 일치) |
| 확률 합계 경고 | 0건 (추가 40회 별도 확인) |

엔딩은 12종에 걸쳐 분산되며 최다 빈도인 "잊힌 유망주"도 26.2%로 특정 엔딩 편중은 없습니다. 특성은 최다 보유율이 "연습벌레" 41.7%로, 이전 버전(73%)보다 크게 완화됐습니다. v2.1에서 확률 기반 선택지·리스크 훈련 도입에 맞춰 특성 획득 확률과 저니맨/새가슴 엔딩·특성 조건을 세 차례 추가로 낮췄습니다.

### v1 기준 밸런스 (참고)

무작위 선택 20회 + 집중 육성 24회 자동 플레이로 측정했습니다.

| 지표 | 값 |
|---|---|
| 플레이어 통산 WAR (무작위 플레이) | 중앙값 27, 상위 25% 37 |
| 플레이어 통산 WAR (집중 육성) | 타자 32 / 투수 49 / 포수 33 |

MVP는 집중 육성에서도 커리어당 평균 1회입니다. AI가 실제 경쟁자가 되면서 수상이 쉬워지지 않도록 맞췄습니다. 개발 중 세 번의 재조정이 있었습니다: AI 성장을 잠재력 수렴 모델로 교체(2군에 갇히는 라이벌 버그 해결), 투수 ERA 스케일 현실화(포지션 간 WAR 불균형 해결), 노쇠화 강화(24시즌짜리 커리어 방지).

## 5. 콘텐츠 추가하는 법

**구단 전용 이벤트** — `TEAM_EVENTS`에 `team:'busan'`(특정 구단) 또는 `cul:'육성'`(문화 공용)을 붙여 추가:

```js
EV({id:'TE_BUSAN_2', team:'busan', w:6, when:p=>p.age>=28,
  title:'사직의 밤',
  text:p=>`3만 관중이 그의 이름을 부른다.`,
  choices:[{t:'응답한다', s:'팬 평가 ↑', run:p=>{p.fanRating+=5;return['그 소리를 오래 기억했다.'];}}]})
```

**구단 성향** — `CULTURE`의 `fa / trade / youth / vet`(1~5)과 `style`을 바꾸면 트레이드·FA·육성 속도·이벤트 풀이 함께 바뀝니다.

**특성 조합 스토리** — `COMBO_EVENTS`에 `need:['특성A','특성B']`만 적으면 됩니다.

**특성·이벤트·엔딩** 추가법은 1차와 동일합니다. 엔딩 배열은 위쪽이 우선 판정이므로 희귀한 것을 위에 둡니다.

**리그 규모 조정** — `assignRoles()`의 `NEED`(보유 정원)와 `ONE`(1군 정원)만 바꾸면 리그 전체 인원이 조정됩니다.

## 6. 테스트 방법

브라우저 콘솔에서 자동 플레이로 한 커리어를 끝까지 돌릴 수 있습니다.

```js
startGame('테스트','pitcher');
while (G.screen === 'game') {
  G.ui && G.ui.choices ? choose(Math.floor(Math.random()*G.ui.choices.length)) : advance();
}
console.log(G.p.tot, G.p.ending.title);
console.log(L.rec);                       // 리그 통산·시즌 최고 기록
console.log(L.history.slice(-5));         // 최근 5년 역사
console.log(eraPlayers(G.p).slice(0,5));  // 내 시대 최고 선수
```

리그가 건강한지 보는 지표: 1군 인원이 200명으로 유지되는가, 홈런왕이 30개대인가, MVP 시즌 WAR이 8~9인가, 20년 뒤 데뷔한 선수들이 리그 상위권을 채우는가.
